# FabledParties

If you wish to use FabledParties as a dependency in your projects, FabledParties is available through Maven Central
or snapshots through Sonatype.

```xml
<repository>
    <id>magemonkey-snapshots</id>
    <url>https://repo.travja.dev/snapshots</url>
</repository>
...
<dependency>
    <groupId>studio.magemonkey</groupId>
    <artifactId>fabled-parties</artifactId>
    <version>1.0.1-R0.8-SNAPSHOT</version>
</dependency>
```
